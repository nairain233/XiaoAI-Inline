# 小爱内联填充

为超级小爱输入法添加键盘内自动填充支持，让兼容密码管理器的账号、密码建议直接显示在键盘中，点击即可通过系统自动填充。

## 功能

- 在键盘顶部候选／工具区域显示填充建议，不增加键盘高度。
- 圆角建议卡片支持浅色、深色显示，多条建议可横向滑动。
- 点击右侧收起按钮可隐藏建议并恢复原工具栏，不会收起键盘；当前输入会话内不会自动重新展开，切换输入框或发起新的内联请求后可再次显示。
- 凭据选择、解锁和填充由密码管理器与 Android 系统处理，模块不读取密码库，也不记录填充内容。

## 使用条件

- Android 15 及以上。当前主要适配环境为 Android 17 / HyperOS 4。
- 支持现代 API 102 和系统框架注入的框架。
- 超级小爱输入法。当前适配版本为 `0.2.1246.79c64c2b`。
- 支持键盘内联自动填充的密码管理器，已使用 Bitwarden `2026.10.0` 进行验证。

其他系统、输入法或密码管理器版本，以及横屏、悬浮、单手模式和自定义皮肤的兼容性尚未确认。

## 安装与设置

1. 安装模块 APK。
2. 在 LSPosed 中启用「小爱内联填充」，作用域勾选「系统框架」和「超级小爱输入法」。
3. 重启手机，使模块加载到相关进程。
4. 将超级小爱设为默认输入法。
5. 将密码管理器设为系统自动填充服务，并在密码管理器中开启键盘内联展示。
6. 打开模块，确认已连接框架，并开启「启用键盘内联填充」。

更新模块后需重新加载相关进程；涉及系统侧的更新通常需要重启手机。

## 使用方法

打开应用或网站的登录页面，点击账号或密码输入框。当密码管理器提供匹配条目时，建议会显示在小爱键盘顶部；点击建议，按密码管理器提示解锁并完成填充。

也可以在模块中点击「打开自动填充测试」，按页面说明创建测试条目，检查是否能完成填充。

## 常见问题

**键盘中没有建议？**

确认模块已启用、两个作用域均已勾选且手机已重启；检查默认输入法、系统自动填充服务和密码管理器的键盘内联选项。密码管理器中还需有与当前应用或网站匹配的条目。测试页面可点击「请求自动填充建议」重试。

**模块显示已连接，但仍无法填充？**

框架连接仅表示模块能与 LSPosed 通信。实际填充还取决于输入框是否支持系统自动填充，以及密码管理器是否返回建议。可先使用模块内的测试页面检查。

**收起建议后如何再次显示？**

切换到新的输入框，或在测试页面重新请求自动填充建议。收起按钮仅隐藏当前会话的建议，不会关闭自动填充功能。
